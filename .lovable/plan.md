## ארגון מחדש של עמוד המצגות (`/resources/presentations`)

המטרה: דף ברור, קצר וניווט נוח — 7 קטגוריות + תגיות + חיפוש וסינון. ללא שינוי בכלי המצגת עצמו, בקישורים, בחיפוש הכללי באתר או ביועץ החכם.

---

### 1. שינויים במסד הנתונים

**טבלה `knowledge_resources`** — הוספת:
- עמודה חדשה `presentation_category` (טקסט, nullable) — לאחת מ‑7 הקטגוריות החדשות.
- עמודה חדשה `tags` (jsonb, nullable) — מבנה: `{ "audience": [...], "stage": [...], "topic": [...] }`.

**הסרה מהמצגות**: סרטון "כאן מתחילה העזרה" — יעודכן ל‑`is_published=false` בקטגוריית `presentations` (נשאר משובץ בעמוד הבית כפי שהוא).

**עדכוני נתונים** — מיפוי 24 המצגות הנותרות לקטגוריות חדשות + תגיות לפי הטבלה:

### 2. עמוד ראשי `/resources/presentations`

**כותרת**: "מרכז הידע למטפלים ובני משפחה"
**טקסט פתיחה**: "לפניכם אוסף מצגות ממוקדות ומבוססות ידע, שנועדו לסייע בהתמודדות עם מצבים מרכזיים בתחום הסיעוד והטיפול."

**רכיבים**:
1. כפתור חזרה ("חזרה לכלים ומשאבים") — כבר קיים, נשאר.
2. שדה חיפוש חופשי (קיים — נשאר).
3. רשת של 7 כרטיסי קטגוריות (3×3 / 2×2 ברספונסיב), כל כרטיס: שם הקטגוריה + מספר מצגות + אייקון. ברקע גוון תכלת בהיר (בסגנון הכרטיסי שכבר השתמשנו בספריית המשאבים במרכז הידע).

תוצאות חיפוש חופשי בעמוד הראשי מציגות מצגות תואמות מכל הקטגוריות (כרטיסי מצגות, לא קטגוריות).

---

### 3. עמוד קטגוריה `/resources/presentations/:categorySlug`

מסלול חדש. תוכן:
1. פירורי ניווט / כפתור חזרה ל"כל המצגות".
2. כותרת הקטגוריה + תיאור קצר.
3. שדה חיפוש פנימי בקטגוריה.
4. שלוש רצועות פילטרים (Toggle group / chips): **סוג משתמש**, **שלב**, **נושא**. ניתן לבחור כמה. החיפוש והפילטרים פועלים בשילוב (AND בין קבוצות, OR בתוך קבוצה).
5. רשימת כרטיסי מצגות. כל כרטיס מציג: כותרת, תיאור קצר, ותגיות בתחתית.

קומפוננטת `ResourceCard` הקיימת תיוותר; נוסיף וריאנט קל שמציג גם את התגיות מתחת לתיאור (Badge בגוון שקוף). אין שינוי בקליק, בפתיחת המצגת, או בזרימה.

---

### 4. שינויים נוספים

- **דף הבית של הכלים והמשאבים** (`/tools-resources`): הכרטיס "מצגות" יקשר לעמוד החדש (אותו URL `/resources/presentations`) — אין שינוי בקישור.
- **חיפוש כללי באתר / יועץ חכם / קישורים מתוך פרקים**: ללא שינוי. הם ממשיכים להגיע ישירות לכל מצגת לפי `id`/`url`.
- **העמוד הקיים `ResourceCategoryPage`**: נשמר עבור `videos` ו‑`forms` — לא נשנה אותם.

### פרטים טכניים (למפתחים)

- **Migration**: `ALTER TABLE knowledge_resources ADD COLUMN presentation_category text, ADD COLUMN tags jsonb;` + `UPDATE` לכל 24 המצגות; `UPDATE ... SET is_published=false` לסרטון הפתיח.
- **קובץ נתונים `src/lib/presentation-categories.ts`**: 7 הקטגוריות (id, slug, title, description, Icon).
- **דפים חדשים**:
  - `src/pages/PresentationsHub.tsx` — דף ראשי עם 7 כרטיסים + חיפוש (יחליף את `ResourceCategoryPage` עבור `presentations`).
  - `src/pages/PresentationCategoryPage.tsx` — דף קטגוריה עם פילטרים.
- **קומפוננטות חדשות**: `PresentationFilters.tsx` (3 קבוצות chips). הרחבת `ResourceCard` לתצוגת תגיות אופציונלית.
- **ניתוב ב‑`App.tsx`**:
  - `/resources/presentations` → `PresentationsHub`
  - `/resources/presentations/:categorySlug` → `PresentationCategoryPage`
  - השאר (`/resources/videos`, `/resources/forms`) ללא שינוי.
- **טיפוסים**: `tags` ב‑`Resource` כ‑`{ audience?: string[]; stage?: string[]; topic?: string[] } | null`.
