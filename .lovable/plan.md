
## הקובץ ברור — כל השאלות שנשאלו נענו

**מה השתנה לעומת הגרסה הקודמת:**
1. שלבים A–E (במקום 1–4)
2. הקדמה: Teal הקיים `hsl(195,60%,36%)`, להתעלם מ-hex, להוסיף Tabler לצד lucide (לא להחליף), כל המספרים דינמיים
3. שלב C משודרג: רצועת 4 מספרים, מקטע ב צומצם ל-3 כרטיסים (בלי "כלים נוספים"), מקטע ג חדש לתרגול קוגניטיבי
4. שלב E חדש: תשתית תשלומים מוכנה אך מנוטרלת (`MONETIZATION_ENABLED=false`)
5. A.4 חודד: להסיר "חזרה לדף הבית" רק מעמודים שכבר קיבלו breadcrumb

**מה לא משתנה:** כלים, תוכן, יועץ חכם, חיפוש גלובלי, מרכז הידע, מערכות קיימות (חיפוש עובד זר, נותני שירות, עמותות, קח תן), שאלון מיפוי, תרחישים, צ'קליסט, מילון, לוגו, פונט, RTL.

## תכנית הרצה — 5 שלבים נפרדים, אישור בין שלב לשלב

### שלב A — תשתית גלובלית (סרגל / breadcrumbs / footer)

**קבצים שייגעו:** `src/components/layout/Header.tsx`, `src/components/layout/Footer.tsx`, `src/components/layout/Layout.tsx`, רכיב חדש `Breadcrumbs.tsx`, רכיב חדש `AdvisorSearchBar.tsx` (פותח את `SmartAdvisor` הקיים), שילוב breadcrumb בכל עמוד פנימי קיים.

- סרגל חדש: לוגו מימין + 6 פריטים משמאל (בית · מרכז הידע · כלים ומשאבים · שירותים וקהילה · צור קשר · CTA יועץ חכם בתכלת מלא). Sticky, רקע לבן, גובה ~64px.
- שדה יועץ חכם מקוצר זמין מתחת לסרגל בכל עמוד (placeholder + אייקון בועה).
- `Breadcrumbs` בראש כל עמוד פנימי (לא בבית), מבוסס route, פונט 12px אפור.
- מסירים את הכפתור הישן "← חזרה לדף הבית" **רק מעמודים שקיבלו breadcrumb** (כל הקיימים יקבלו ביחד באותו PR — אין רגע ללא דרך חזרה).
- Footer: וידוא קישורים אודות / צור קשר / תקנון / פרטיות.
- ה-routes הישנים (`/tools`, `/foreign-worker-search`, `/organizations`, `/give-take`, `/cognitive-training` וכד') נשארים פעילים כדי שלא יישברו קישורים — רק נעלמים מהסרגל.

### שלב B — עמוד חדש `/services-community`

**קובץ חדש:** `src/pages/ServicesCommunity.tsx` + route ב-`App.tsx`.

- כותרת + תת-כותרת + breadcrumb.
- גריד 2x2 של 4 כרטיסי מערכות עשירים (אייקון עגול + 3 pills + "היכנסו למערכת ←"):
  1. חיפוש עובד זר → `/foreign-worker-search`
  2. חיפוש נותני שירות → `/ad-elai`
  3. סיוע מעמותות → `/organizations`
  4. קח תן → `/give-take`

### שלב C — עמוד חדש `/tools-resources`

**קובץ חדש:** `src/pages/ToolsResources.tsx` + route. **לא** מוחקים את `/tools` הקיים — הוא נשאר עד החלטה אחרת.

- כותרת + תת-כותרת + כפתור pill "מה יש בכלים? — מדריך מהיר" שפותח modal (תוכן ה-modal הקיים מ-`/tools` הנוכחי, או חדש מבוסס `digitalToolCategories`).
- שדה חיפוש מקומי (filter לפי שם/תיאור).
- **רצועת 4 מספרים** דינמיים (כלים אינטראקטיביים / מצגות / טפסים / מדריכים) — נשלפים מ-`digitalTools`, presentations data, `forms`, ומספר guides. נחשב מתוך מקורות הנתונים הקיימים, לא hard-coded.
- מקטע א — 4 כרטיסי "כלים מובילים" אינטראקטיביים + קישור "לכל הכלים ←" (פותח את כל הרשימה או מסנן).
- מקטע ב — 3 כרטיסים בלבד: טפסים / מצגות / מדריכים (רקע אפור עדין, ללא border, עם מספר פריטים דינמי).
- מקטע ג — כרטיס יחיד רחב לתרגול קוגניטיבי, רקע כחלחל בהיר, CTA → `/cognitive-training`.

### שלב D — דף הבית (`src/pages/Index.tsx`)

- שמירה על Hero (סרטון + כותרת + 2 כפתורים), הסרת "← הקליקו כאן להתחיל בניווט", הקטנה ל-~60vh.
- מקטע יועץ חכם חדש מתחת ל-Hero (pill חיפוש + 3 צ'יפים + קישור משני לשאלון).
- "לא יודעים מאיפה להתחיל?" — 3 כרטיסי כניסה (שאלון מיפוי / זיהוי תרחיש / מרכז הידע).
- רצועה "כלים מובילים" (4 כרטיסים לבן + border) + קישור לכל הכלים.
- רצועה "המערכות שלנו" (4 כרטיסים אפרפרים, ללא border) + קישור לכל השירותים.
- הסרה: סקשן 11 הפרקים, כפתורי "צעדים ראשונים"/"כלים יישומיים" שמעליו, וסקשן החיפוש התחתון.

### שלב E — תשתית תשלומים (מנוטרלת)

- קובץ הגדרות מרכזי `src/lib/monetization.ts` עם `MONETIZATION_ENABLED = false`.
- שדה `isPaid?: boolean` כבר קיים על `digitalTools` — נוודא שכולם `false`.
- מיגרציה: עמודה `has_premium boolean default false` בטבלת `profiles` (אם אין `profiles` — ניצור).
- helper `canAccessTool(tool, user)` — מחזיר `true` כל עוד הדגל כבוי.
- דף `/premium` עם Stripe Checkout — נבנה רק אם המשתמש מאשר, **אחרת נדלג ונשאיר רק את המבנה הלוגי**. הפעלת Stripe דורשת התקנת תוסף Lovable Payments בנפרד — אבדוק/אבקש אישור לפני.
- Badges (🔒 Premium, external-link) — קוד מוכן בכרטיסי הכלים אבל לא מתרנדרים בגלל הדגל.

## נקודות לאישור לפני שמתחילים

1. **סדר ההרצה:** מאושר A → B → C → D → E עם אישור ביניים בין שלב לשלב? (מומלץ)
2. **שלב E / Stripe:** האם להפעיל באמת תוסף Lovable Payments עכשיו (כרוך בהתקנה ובתשלום פלטפורמה), או רק להכין סקאפולד קוד + מיגרציית `has_premium` בלי התקנת התוסף? המלצתי: **רק סקאפולד עכשיו**, התקנת Stripe ביום שתרצה לחייב.
3. **`/tools` הישן:** להשאיר פעיל במקביל ל-`/tools-resources` החדש (בטוח לקישורים), או להפנות עם redirect?
4. **Tabler icons:** מאשר התקנת `@tabler/icons-react` (תוספת ~50KB tree-shaken) לעמודים החדשים בלבד?

אענה על תשובותיך ואחיל את שלב A קודם.
