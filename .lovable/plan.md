

## תיקון מנוע ההפניות: מנוע חוקים דטרמיניסטי

### הבעיה
ה-AI לפעמים מחזיר כלים כמו "סנכרון" ו"מרכז הידע" אבל מפספס את הכלים בתשלום כמו "כתיבת צוואה" ו"מדריך ייפוי כוח מתמשך". הבעיה: ה-AI מחליט לבד מה רלוונטי — אין ערובה שיציג את כל הכלים.

### הפתרון: מנוע חוקים קשיח **אחרי** תשובת ה-AI

לא מחליפים את ה-AI — מוסיפים שכבת חוקים שמוסיפה כלים חובה לפי מילות מפתח בטקסט של המשתמש. ה-AI עושה את שלו, ואז המנוע מזריק כלים שחסרים.

### מיפוי מילות מפתח → כלים חובה

| מילות מפתח | כלים שנכפים |
|---|---|
| צוואה, ירושה | כתיבת צוואה (בתשלום), סנכרון טיפול, מרכז הידע |
| ייפוי כוח, אפוטרופסות | מדריך ייפוי כוח (בתשלום), סנכרון טיפול, מרכז הידע |
| דמנציה, אלצהיימר, שכחה | אימון קוגניטיבי, מרכז הידע, הערכת מצב |
| עובד זר, מטפל צמוד | חיפוש עובד זר, מחשבון שכר (בתשלום) |
| ציוד, חיתולים, כסא גלגלים | קח ותן |
| שחיקה, עייפות, לחץ | הערכת מצב, מפת שירותים |
| חוזה העסקה | הסבר על חוזה (בתשלום), תאום ציפיות (בתשלום) |

### שינויים בקבצים

| קובץ | שינוי |
|---|---|
| `supabase/functions/smart-advisor/index.ts` | הוספת מנוע חוקים: סריקת מילות מפתח → מיזוג כלים חובה לתוצאת ה-AI. כלים בתשלום מסומנים עם `isPaid: true` |
| `src/components/knowledge/SmartAdvisor.tsx` | הוספת תגית "בתשלום" ליד כלים עם `isPaid`, שיפור הממשק |
| `src/components/knowledge/ScenarioExplorer.tsx` | הוספת כלים בתשלום ל-SITE_TOOLS (צוואה, ייפוי כוח) עם תגית בתשלום |
| `src/pages/DigitalTools.tsx` | תמיכה ב-hash scroll — כשנכנסים עם `#will-template` גוללים לכלי הרלוונטי |

### איך זה עובד טכנית

```text
משתמש כותב: "לאמא אין צוואה והיא דמנטית"
         ↓
   AI מחזיר site_tools (מה שהוא בחר)
         ↓
   מנוע חוקים סורק מילות מפתח:
     • "צוואה" → מוסיף: כתיבת צוואה, סנכרון, מרכז הידע
     • "דמנטית" → מוסיף: אימון קוגניטיבי, מרכז הידע, הערכת מצב
         ↓
   מיזוג (ללא כפילויות) → תוצאה סופית עם כל הכלים
```

### תוצאה צפויה
לשאילתה "לאמא אין צוואה והיא דמנטית" יוצגו **תמיד**:
- כתיבת צוואה (בתשלום) ← `/tools#will-template`
- מדריך ייפוי כוח מתמשך (בתשלום) ← `/tools#poa-guide`  
- כלי סנכרון טיפול משפחתי ← `/tools#family-sync`
- אימון קוגניטיבי ← `/cognitive-training`
- מרכז הידע ← `/knowledge-center`
- שאלון הערכת מצב ← `/tools`
